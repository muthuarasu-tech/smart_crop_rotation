What the metrics mean

  • Accuracy - fraction of test crops correctly predicted.
  • Precision - of the crops the model predicted, how many were correct per class (macro average).
  • Recall - of the actual crops, how many the model caught per class (macro average).
  • F1 Score - harmonic mean of precision and recall; balanced, useful for multi-class tasks.
  • Best model - chosen by highest F1 and saved as models/crop_model.pkl.
