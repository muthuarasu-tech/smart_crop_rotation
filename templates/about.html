ℹ About Smart Crop Rotation

AI-Based Intelligent Crop Rotation Recommendation System

Platform Overview

Smart Crop Rotation is an intelligent decision-support platform that helps farmers choose which crop to plant next season by combining several decision layers:

  • ✓ Machine Learning models (Decision Tree, Random Forest, Gradient Boosting, KNN)
  • ✓ Agronomic crop-rotation rules (crop families, nitrogen fixing)
  • ✓ Soil nutrient management (N-P-K, pH)
  • ✓ Environmental conditions (rainfall, temperature, humidity, water)
  • ✓ Sustainability and soil-health scoring
  • ✓ Explainable recommendations ("Why this crop?")

Technology Stack

  • Frontend: HTML5, CSS3, JavaScript, Chart.js
  • Backend: Python 3.11+, Flask
  • Data Science: Pandas, NumPy, Scikit-learn
  • Visualisation: Chart.js (web), Matplotlib (notebook)
  • Model storage: Joblib
  • Database: SQLite (stdlib sqlite3)
  • Charts offline fallback: chart tables still render without internet

How the recommendation works

  1. User enters soil, season and environmental inputs.
  2. The trained ML pipeline predicts a probability for every crop.
  3. crop_rotation.py scores each crop using rotation rules (family, water, disease, season, soil).
  4. soil_analysis.py computes Soil Health and Sustainability scores.
  5. The final ranking combines ML (45%) + rotation rules (40%) + environment (15%).
  6. The top crop plus three alternatives are shown with full explanations.

Scoring Model

The platform scores every candidate crop using three complementary metrics:

  • ✓ Soil Health (0–100): nutrient balance (N-P-K, pH) against crop requirements
  • ✓ Rotation Score (0–100): crop-family rotation, nitrogen fixing, water/disease carryover
  • ✓ Sustainability (0–100): soil-friendly farming practices score

Data & Responsibility

Models are trained on a structured agricultural dataset bundled with the platform and continuously logged as recommendations are made. Recommendations are decision-support estimates — always validate planting decisions with local soil testing and certified agronomic advice.
